# ConectaUNET 🎓

**Proyecto para la materia de Multimedia**

ConectaUNET es una plataforma colaborativa diseñada para centralizar la vida universitaria. Nuestro objetivo es unificar en un solo lugar la difusión de eventos culturales y servir como vitrina para los emprendimientos estudiantiles, solucionando así la dispersión de información en el campus de la UNET.

## 🚀 Tecnologías y Enfoque

El proyecto está diseñado bajo un enfoque **Mobile First**, garantizando una experiencia de usuario óptima desde dispositivos móviles. 

**Stack Tecnológico:**
* **Frontend:** Vue.js y Tailwind CSS
* **Backend:** Node.js y MongoDB
